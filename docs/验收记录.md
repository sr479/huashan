# 花山节首版验收记录

验收环境：本机 Node.js 22、SQLite、内置浏览器。业务操作使用独立的临时数据库，不修改交付环境的初始示例数据。

## 自动化验证

- 15 项业务与 HTTP 集成测试通过。
- 还衣截止时间按北京时间判断，覆盖当日截止时间前后、逾期锁定和续租恢复。
- TypeScript 类型检查和前端、服务端生产构建通过。
- 本地数据库与实拍备份脚本实际执行成功。
- Docker Compose 配置校验通过；生产镜像可构建。

## 浏览器验证

1. 顾客端查看服装、价格、预计归还、最早预计可租与月历。
2. 手机端填写称呼、手机号、备注，同意租赁规则后提交预约，收到唯一预约编号。
3. 后台接收预约并确认，锁定租期及清洗时间。
4. 分别登记租金与押金，再登记取衣，服装更新为出租中。
5. 归还时核对配饰、记录验收结果，服装进入清洗。
6. 登记退还押金，押金余额归零后完成结算。
7. 订单完成后服装仍处于清洗，手动完成清洗检查后恢复在店待租。
8. 手机端新增服装、输入小数价格，保存后顾客端可见且价格正确。
9. 后台排期表可显示出租、已预约、清洗和空档。
10. 390px 和 320px 手机尺寸无页面水平溢出；手机后台导航可正常打开、关闭及跳转。数据表在各自容器中横向滚动。
11. 后台上传图片、保存服装，顾客端正确加载图片并显示小数租金；错误图片格式会被拒绝。
12. 使用预约编号和手机号重新查询回执；弹窗内的复制成功提示可见、可关闭。

## 首版边界

- 当前支付为线下收退登记，未接入支付网关或短信服务。
- 示例插画与示例订单用于体验，正式经营前需要真实服装实拍、库存、门店电话、地址及备案信息。
- 当前交付本地可运行项目与部署配置，未修改腾讯云资源或域名解析。
- 数据库按单店、单服务器使用设计。备份定时器配置已提供，但尚未在服务器启用。
